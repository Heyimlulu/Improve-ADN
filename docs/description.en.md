ADN Improver enhances the ADN (Animation Digital Network) player:

- Theater mode: the player fills the window, the rest of the page stays reachable by scrolling, the header slides back when hovering the top of the screen
- Theater mode button in the player bar
- Control of the dark gradient at the bottom of the picture (hidden with the controls or always hidden)
- Pause overlay with the show and episode title
- Playback speed menu (0.5× to 2×) with optional speed memory
- Picture-in-Picture button
- YouTube-like keyboard shortcuts (space, arrows, J/K/L, M, F, T, P, < >, 0 to 9, Shift + N / Shift + P) with a built-in cheat sheet on ?
- Visual feedback for every action
- Scrollbar hiding
- Only four settings: theater mode, pause overlay, shortcuts, scrollbar

Independent project, not affiliated with ADN.
